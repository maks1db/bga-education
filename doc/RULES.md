# Крестики-нолики — правила (опорный документ разработки)

Классические крестики-нолики для двух игроков.

## Ход игры

1. Играют два игрока на поле 3×3 (9 клеток, номера 0–8 слева-направо, сверху-вниз).
2. Первый игрок ставит крестики (X), второй — нолики (O).
3. Игроки по очереди ставят свой символ в любую свободную клетку.
4. Первый игрок, выстроивший три своих символа в ряд (горизонталь, вертикаль или диагональ), выигрывает.
5. Если все 9 клеток заняты, а ряд не собран, — ничья.

## Состав поля

- 8 выигрышных линий: 3 горизонтали, 3 вертикали, 2 диагонали.

## Победа и счёт

- Победа: 3 в ряд. Ничья: заполненное поле без выигрышной линии.
- Очки на BGA: победа = 2, ничья = 1, поражение = 0 (см. [A3] в ASSUMPTIONS.md).
