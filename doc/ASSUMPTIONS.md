# Допущения (assumptions)

Каждое допущение имеет ID, на который ссылаются код и вопросы автору.

- **[A1]** Поле строго 3×3, варианты размера поля не предусмотрены (game options пуст).
- **[A2]** Первый игрок (стартует игру) играет крестиками (X), второй — ноликами (O). Крестики всегда ходят первыми.
- **[A3]** Очки: победа = 2, ничья = 1, поражение = 0. Это позволяет рейтингу BGA ранжировать ничью выше поражения. Классические правила денежного/очкового счёта не определяют.
- **[A4]** Zombie Mode уровень 1: зомби случайно выбирает любую свободную клетку (`getRandomZombieChoice`).
- **[A5]** Доска хранится в `$this->bga->globals` (массив из 9 ячеек: 0 = пусто, иначе player_id). Отдельные таблицы БД не нужны.
